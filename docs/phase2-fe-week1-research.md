# Phase 2 FE Week 1 Research Notes

## Side-by-side Writing Comparison Patterns

- Use a two-column layout on desktop: student draft on the left, improved version on the right.
- Collapse to stacked cards on mobile to keep reading order natural.
- Show sentence-level pairings below the global analysis so learners can compare line-by-line.
- Keep improvement categories visible as chips (vocabulary, grammar, coherence, structure) for scan speed.

## Roleplay Chat UI Patterns

- Pin scenario context at the top before the first turn so users understand the role and goals.
- Use asymmetric bubbles (assistant left, learner right) with timestamps and clear message grouping.
- Keep input + action controls (send, quick prompts, voice placeholder) in a sticky bottom composer.
- Add typing indicator and conversational turn counter to reinforce real-time agent behavior.
